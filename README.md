**Global Data Jobs Dashboard (2023)**

<img width="1511" height="650" alt="image" src="https://github.com/user-attachments/assets/60a8c099-bb4a-473d-93b5-5943148e4d8c" />

This dashboard provides a comprehensive analysis of global data-related job trends in 2023, offering insights into job demand, salary distribution, and the most sought-after skills in the data industry. It is designed to support data-driven decision-making for aspiring professionals, recruiters, and industry stakeholders.
**1. Job Demand Distribution**

The analysis reveals that Data Analyst and Data Scientist roles dominate the job market, accounting for the highest percentage of demand. Senior-level roles follow, while niche roles such as Cloud and Software-related data positions show relatively lower demand. This highlights a strong market need for core data professionals with analytical and modeling capabilities.

**2. Salary Trends for Top Skills**

An evaluation of the top 10 in-demand skills shows a clear relationship between specialization and compensation. Skills such as SQL, Python, Spark, and Azure command competitive salaries, indicating that technical proficiency in data processing and cloud technologies significantly boosts earning potential.

**3. Hourly vs Yearly Compensation**

The comparison between hourly and salaried employees suggests that yearly employees tend to earn slightly higher overall compensation. However, the trend lines remain closely aligned, indicating that both employment types offer competitive pay depending on experience and role.

**4. Highest Paying Roles**

Among all roles analyzed, Senior Data Scientist emerges as the highest-paying position, followed closely by Senior Data Engineer and Data Scientist roles. This reinforces the value of experience, advanced analytics skills, and domain expertise in driving higher salaries.

**5. Top Data Skills**

The most in-demand skills across the dataset are:

- SQL (43%)

- Python (41%)

- Tableau

These results emphasize the importance of combining programming, database management, and visualization skills to remain competitive in the data field.

Interactive Features

The dashboard includes dynamic filters (Control Panel) such as:

- Job Group (e.g., Data Gurus, Senior Data Gurus)

- Country (multi-country analysis)

- Salary Rate (Hourly vs Yearly)

These controls allow users to customize their analysis and explore trends across different regions, experience levels, and compensation structures.
